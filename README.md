# YouTube Sheet Music to PDF Extractor

A powerful desktop application designed to automatically download sheet music from videos YouTube with detect page turns, extract high-resolution page images (`page-01.png`, etc.), and merge them into a single PDF.

---

## ✨ Features
* **Multi-Language Support:** Instant toggle between Greek (GR) and English (EN).
* **Automatic Scene Detection:** Smart algorithm that scans the video and detects sheet music page transitions automatically.
* **Manual Mode:** Option to input custom timestamps separated by commas.
* **YouTube Metadata Integration:** Automatically extracts the video title to use as the PDF filename.
* **Auto-Open & Cleanup:** Automatically opens the generated PDF upon completion and cleans up temporary files.

---

## 🚀 How to Run

1. Download the latest release from this repository and extract zip file.
2. Double-click the executable file to launch the application — **no installation or additional dependencies are required**.
3. Paste the YouTube video URL, select **Auto** or **Manual** mode, choose your destination folder, and click **Start Extraction**.
